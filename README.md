## Trabajos destacados

- [Laberinto](04-matematicas-para-automatica-y-robotica/trabajos/laberinto/) · **C++**: cinco algoritmos de búsqueda (BF, DF, Best First, A\*, IDDF) comparados en 12 laberintos.
- [Sudoku: CSP vs. máximo clique](04-matematicas-para-automatica-y-robotica/trabajos/sudoku-csp-max-clique/) · **MiniZinc, C++ y BitGraph**: el mismo Sudoku como CSP y como problema de clique máximo.
- [Robot camarero](08-guiado-y-navegacion-de-robots/trabajos/robot-camarero-restaurante/) · **MATLAB**: navegación en un restaurante con A\*, EKF y control reactivo.
- [Taller METATOOL](03-inteligencia-artificial/trabajos/pddl-taller-metatool/) · **PDDL**: planificación automática de un robot que usa, busca, fabrica o inventa herramientas.
